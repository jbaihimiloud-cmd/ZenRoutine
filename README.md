# روتيني الهادئ — Android

تطبيق Android أصلي بسيط بـ Kotlin: خمس مراحل يومية، تغيير الأوقات، تفعيل/إيقاف كل تنبيه، متابعة الإنجاز اليومي، وتنبيهات محلية تعاد جدولتها بعد التشغيل.

## بناء APK
1. افتح المجلد في Android Studio (نسخة حديثة تدعم Android Gradle Plugin 8.7.3).
2. ثبّت Android SDK 35 وJDK 17 إذا طلب البرنامج ذلك، وانتظر Gradle Sync.
3. اختر Build > Build APK(s).
4. الملف الناتج: app/build/outputs/apk/debug/app-debug.apk.

## ملاحظات
- يعمل دون خادم ودون إنترنت بعد التثبيت.
- في Android 13+ يلزم السماح بالإشعارات؛ وفي Android 12+ يفضّل السماح بالمنبهات الدقيقة.
- بعض الهواتف تؤخر التنبيهات بسبب قيود البطارية. السماح بالتشغيل في الخلفية قد يحسن ذلك.
- لم يُبنَ APK داخل هذه البيئة؛ المشروع جاهز للبناء باستخدام Android Studio.

## بناء APK من الهاتف باستعمال GitHub Actions
1. أنشئ مستودع GitHub جديداً (يمكن أن يكون Private).
2. ارفع **محتويات** مجلد zen_daily_android إلى جذر المستودع، مع إظهار المجلد المخفي `.github/workflows`.
3. افتح تبويب Actions ثم workflow باسم Build Android APK، واضغط Run workflow (أو ادفع الملفات إلى main).
4. بعد نجاح التنفيذ، افتح صفحة التشغيل وانزل إلى Artifacts وحمّل ZenRoutine-debug-APK.
5. فك الضغط عن artifact وثبّت app-debug.apk على هاتفك بعد التحقق من مصدره.

ملاحظة: لم يتم تشغيل بناء GitHub Actions هنا؛ النجاح يحتاج التحقق من سجل البناء. هذه نسخة debug للتجربة، وليست نسخة متجر موقّعة للنشر.
